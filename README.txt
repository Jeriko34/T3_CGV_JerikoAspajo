First Person Shooter - T3

Juego para el examen T3 del curso Computación Gráfica y Visual.
Aquí, el personaje debe adentrarse por un almacén, haciéndose cargos de zombies para llegar al ascensor.
Las armas son limitadas, y encontrarás municiones por todo el nivel, aunque algunas esten resguardadas por infectados...
Puedes matar a los zombis de 2 disparos, pero al mismo tiempo, si uno de ellos te toca, perdiste y debes reiniciar de nuevo.

Autor: Jeriko Aspajo Ugaz -  N00411297

1. Requisitos:
- Navegador con WEBGL habilitado.
- Python 3 (Windows o macOS) o extensión LIVESERVER de Visual Studio Code.
- Conexión a Internet: Three.js se importa desde jsDelivr (versión fija `0.180.0`).
- NO NECESITAS `npm install` ni instalar BLENDER para ejecutar este proyecto.

2. Instrucciones:
-Dirijase al repositorio de Github del proyecto, y descargue todos los archivos.
-Abra VisualStudioCode y coloque todos los archivos en una carpeta.
-Abra el archivo index.html con LiveServer.

3. Controles
W -> Avanzar
S -> Retroceder
A -> Desplazarse a la izquierda
D -> Desplazarse a la derecha
Movimiento del mouse -> Orientar Cámara
Clic Izquierdo -> Disparar
Tecla 1 -> Seleccionar arma 1 (Shotgun)
Tecla 2 -> Seleccionar arma 2 (Rifle)
